# Složka pro obrázky a certifikáty

Zde můžeš nahrát své vlastní obrázky:
- **Fotka diplomu:** Nahraj sem soubor např. `diplom.jpg` nebo `diplom.png`.
- V souboru `index.html` stačí změnit cestu v sekci diplomu:
  ```html
  <img src="assets/img/diplom.jpg" alt="Diplom z AI olympiády - Šimon Tobiáš" ...>
  ```
- Dokud sem vlastní fotku nenahraješ, web automaticky používá připravený grafický vektorový náhled `placeholder-diplom.svg`.
